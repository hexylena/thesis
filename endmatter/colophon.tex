	\lettrine[lines=3,lraise=0.30,lhang=0.3,findent=0.5em,nindent=0em]{\textcolor{hexy-red}{\fontEBGaramondInitials{}T}}{his thesis was typeset} using \XeLaTeX, a UTF-8 native version of \LaTeX which was originally developed by Leslie Lamport and based on Donald Knuth's \TeX. The artwork for this book was produced by hexylena, with Inkscape 1.4, and a dreadful touchpad. A number of fonts have been used in this book, which the author wishes to note specially:
	\begin{itemize}
		\item \textbf{EB Garamond} at 10pt is used for the body of this book. It is an implementation of Claude Garamont's Antiqua typeface Garamond, designed by Robert Granjon. Its letter forms are taken from the Egenolff-Berner specimen printed in 1592. Licensed OFL-1.1.
		\item \textbf{Qiji} is a Ming era typeface extracted by Lingdong Huang, from Ming Dynasty woodblock printed books ({\fontQiji{}凌閔刻本}), using semi-automatic computer vision and OCR. It was named in honour of {\fontQiji{}閔齊伋}, a \nth{16} century printer. Qiji is visible on the back cover, as well as the stellingen. License OFL-1.1.
		\item \textbf{0xA000} ``a meta-modular tile-grid based font-family'' designed by Øyvind Kolås where each character is described by a small grid which can then be transformed into different representations. 0xA000-Dots is used on the cover. License OFL-1.1.
		\item \textbf{IM Fell English} an implementation of the `Dutch Fell Types' by Igino Marini, based on the work of Dr. John Fell and Peter De Walpergen in the 1600s. Lin Yangchen's blogpost about the use of it for his own dissertation. Used in the iceberg graphic in the discussion. License OFL-1.1.
		\item \textbf{Gorton Perfected} a classic machining font, based on the George Gorton Machine Co. series of engraving machines and designed by Inga Plönnings. Used for my name on the cover. \emph{Licensed}.
		\item \textbf{Nyght Serif} is used to render my name on the cover, a gorgeous caligraphic typeface developed by Maksym Kobuzan with Tunera Type Foundry. License OFL-1.1.
		\item A custom set of serif Cistercian numerals was self-designed, inspired by FRB Cistercian and Kirk Miller's Unicode proposal, specifically Agrippa of Nettesheim's rendition.
	\end{itemize}
}
